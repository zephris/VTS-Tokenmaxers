# Hackathon Judging Criteria

Source checked: https://ultimate-hackathon.vercel.app/side-quests

## What The Website Publishes

The website does not publish a formal judging rubric, scorecard, weighting system, or detailed grading criteria on the Side Quests page.

It does state three baseline project requirements:

1. Build a web interface.
2. Include a data component.
3. Include an AI-powered feature.

The encrypted chat app should therefore be presented as a working web product, demonstrate meaningful data handling such as conversation/transcript state, and make the AI-generated steganographic carrier text a visible part of the core workflow.

## Side Quest Scoring

Side quests provide bonus points by difficulty:

- Easy: 1 point
- Medium: 3 points
- Hard: 5 points

These values describe side-quest bonuses, not a complete judging rubric. Some side quests also identify a marker or checker requirement; those task-specific checks should be treated as acceptance criteria for the relevant side quest.

## Practical Interpretation

Because no formal rubric is shown, the safest demo strategy is to make the required elements easy to verify: show the pre-encryption message, generated cover text, recovered post-decryption message, the data/state used to keep both participants synchronized, and a clear explanation of where the local language model is used.
