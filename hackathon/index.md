# Silent Outposts — working index

We are solving only **The Silent Outposts**, a thread in the **Sunken Garden & CS Building** region.

## The problem

The robots rely on a damaged relay network whose messages can be copied or spoofed by peacocks. Some outposts have stopped broadcasting because they fear impersonation. As trust in the network collapses, genuine emergency calls and meaningful periods of silence are both being ignored.

Our product should help survivors notice outposts that may have gone silent and distinguish urgent genuine signals from misleading traffic.

## Required deliverables

The main hackathon submission must contain:

- A web interface a survivor could use.
- A data component such as a chart, table, or trend view.
- An LLM-powered feature that performs useful work in the workflow.
